# Jiawen Ji — Professional Portfolio

Editorial portfolio site for DTAN500 / 2026. Built with React, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

The app is a static Vite build (`dist/`) and deploys cleanly to Vercel or Netlify.

- **Vercel:** import the repository and use the defaults (`npm run build`, output `dist`).
- **Netlify:** same build command and publish directory.

## Content

Assessment copy, competency descriptions, and the professional development roadmap live in `src/data/` so they can be updated without rewriting components.
